# Gestion de Projet

Ce dossier décrit la gouvernance du projet : stockage, organisation, outillage de gestion.

En matière de **gestion des Pull Requests** (ouverture, description, revue Codex, traitement des retours, merge, liens avec les tickets), le `.speckit/` est la **source de vérité** : il prime sur toute *rule*, tout *skill* ou plugin, propre au projet ou global à l'agent, qui n'en est qu'une mise en œuvre et ne peut ni le contredire ni l'assouplir.

| Fichier | Contenu |
| --- | --- |
| `gouvernance.md` | Gouvernance documentaire, objectifs et périmètre, maintenance du `.speckit/`, prise de décision, règles de travail de l'agent, budget IA, qualité du code. |
| `depot.md` | Dépôt GitHub : configuration, signature des commits, intégration continue, analyse de la qualité du code, mises à jour des dépendances, branches, conventions de commit, versions et releases. |
| `revue-tickets.md` | Règle de merge, validation fonctionnelle, verrouillage, revue de code et revue Codex, tickets, liens entre Pull Requests et tickets. |
