# Maquettes

Toutes les déclinaisons sont présentées côte à côte par la visionneuse [`maquettes/fusion/`](../maquettes/fusion/index.html) (cf. [Maquettes](../charte-graphique/maquettes.md)). Elles ont une source commune, `mockup.html`, que chacune affiche avec son thème, choisi par le paramètre `theme` (mêmes valeurs que pour la page d'accueil de l'administration, [Maquettes](../administration/maquettes.md)).

Réglages de la source commune :

| Réglage | Valeurs |
| --- | --- |
| `exemple` | `auteur` (par défaut) : deux auteurs ; `genre` : deux genres ; `univers` : deux univers et leurs sous-univers homonymes ; `univers-imbrique` : un univers et l'un de ses sous-univers, dont le parent est impossible |
| `choix` | `en-cours` (par défaut) : des données restent à choisir ; `complet` : tout est choisi |
| `dialogue` | `aucun` (par défaut) ; `confirmation` : la confirmation ouverte, tout étant choisi |
| `menuOpen` | menu de l'administration ouvert |

Les données sont fictives.
