# Maquettes

Toutes les déclinaisons sont présentées côte à côte par la visionneuse [`maquettes/journal/`](../maquettes/journal/index.html) (cf. [Maquettes](../charte-graphique/maquettes.md)). Elles ont une source commune, `mockup.html`, que chacune affiche avec son thème, choisi par le paramètre `theme` (mêmes valeurs que pour la page d'accueil de l'administration, [Maquettes](../administration/maquettes.md)).

Réglages de la source commune :

| Réglage | Valeurs |
| --- | --- |
| `filtres` | panneau des filtres ouvert, une opération choisie |
| `fiche` | historique d'une fiche : le journal filtré sur un album |
| `recherche` | une recherche sur le libellé des fiches |
| `actions` | menu d'une entrée ouvert |
| `vide` | une recherche sans résultat |
| `menuOpen` | menu de l'administration ouvert |

Les données sont fictives.
