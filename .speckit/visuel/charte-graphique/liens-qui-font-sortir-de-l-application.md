# Liens qui font sortir de l'application

> j'aime pas la fleche, mais il faut effectivement indiquer que le lien fait sortir de l'application (exigence de l'utilisateur)

Un lien qui fait sortir de l'application mène à un site qui n'en fait pas partie : le site web d'un éditeur, et tout autre site extérieur à venir. Partout où il apparaît, dans la consultation comme dans l'administration, il le dit :

- **Un petit globe**, qui suit son texte (le nom de l'éditeur, son adresse, « Site web ») : ni flèche, ni mention écrite, ni pastille « www » (décision de l'utilisateur, parmi ces trois propositions). Un bouton qui n'a qu'une icône (ouvrir le site saisi d'un éditeur) a le globe pour icône, comme une entrée de menu, dont l'icône précède le libellé (le site web d'un éditeur, dans le menu de sa ligne).
- **Seulement ce qui sort de l'application** : ce qui s'ouvre dans un nouvel onglet sans quitter l'application (l'image originale d'un visuel) n'a pas le globe.
- **Distinct de l'icône des univers**, globe à un seul équateur : le globe d'un lien sortant est tracé de deux parallèles.
- **Distinct d'un lien qui reste dans l'application** : « Voir dans la consultation » ou « Aller à la consultation », de l'administration, gardent leur flèche, qui ne désigne plus jamais un site extérieur.
- **De la couleur du lien qu'il suit**, dans chaque thème.
- **Annoncé aux lecteurs d'écran** : le lien se lit suivi de « site externe ».
